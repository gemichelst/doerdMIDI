📋 Über das Projekt

doerdMIDI ist eine Sammlung von MIDI-Tools für Musiker und Entwickler. Alle Tools sind browser-basiert und nutzen moderne Web-APIs für die MIDI-Integration.

✨ Features

  • Browser-basierte Tools – keine Installation erforderlich
  • Moderne Web MIDI API Integration
  • Responsive Design für alle Geräte
  • Open Source und kostenlos
  • Echtzeit MIDI-Verarbeitung
  • Intuitive Benutzeroberfläche

🔧 Technische Details

  • Progressive Web App (PWA) Technologie
  • Web MIDI API für Hardware-Integration
  • Responsive CSS Grid Layouts
  • Cross-Browser Kompatibilität
  • Moderne ES6+ JavaScript
  • Performance-optimiert
